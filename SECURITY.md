# Security policy

Panim is an early-development, volunteer-maintained project (one maintainer). There is no released app yet.

## Reporting a vulnerability
Please report privately, not in a public issue or pull request: email **support@panim-app.com** with what you found, how to reproduce it, the commit, and the impact you expect. If GitHub private vulnerability reporting is enabled on this repository, you may use that instead. Do not include real contact data, photos, secrets or other personal data in a report.

No response-time or fix-time commitment is promised. Good-faith research that avoids privacy violations and service disruption is welcome. This policy is not legal advice or a legal commitment.

## Scope
This repository's code and build configuration. Out of scope: third-party services and apps Panim hands off to (Phone, Messages, FaceTime, WhatsApp), social engineering, and findings that require an already-compromised device.

## Supported versions
Only `main` while the project is pre-release.
