# Panim (iPhone and iPad) — foundation build

Panim organizes everyday communication around people: recognize a person, choose a clear action, hand off to a supported provider. Free, open source, noncommercial, ad-free. Built by Avi, sole maintainer.

**Status: M2 foundation only.** The app launches to a placeholder screen. There are no product features, no store listing and no release. Nothing here is tested on a physical device yet.

## Facts about this repository (as of its first commit)
- Native SwiftUI, Swift 6 language mode, **no third-party dependencies**, no network code, **no permissions requested**.
- Targets iPhone and iPad (`TARGETED_DEVICE_FAMILY = 1,2`); deployment target iOS 17.0 (a declared floor; only the latest iOS has been exercised).
- Bundle identifier `invalid.panim.poc` is a **non-registered placeholder**. A real identifier, signing team and domain association are still to be chosen before any device install or release.
- **License:** Apache License 2.0 (`LICENSE`, `NOTICE`) for the source code. The Panim name, logo and brand assets are **not** covered by it; they follow `notices/ASSET-LICENSE.md`. The bundled font is under the SIL OFL 1.1.

## Commands that have been run successfully (Xcode 26.0.1, macOS 26.6.2)
```sh
# build app + test bundles
xcodebuild build-for-testing -project Panim.xcodeproj -scheme Panim \
  -destination 'platform=iOS Simulator,name=iPhone 17' -derivedDataPath /tmp/panim-dd
# unit + UI tests on an iPhone and an iPad simulator
xcodebuild test -project Panim.xcodeproj -scheme Panim \
  -destination 'platform=iOS Simulator,name=iPhone 17' -derivedDataPath /tmp/panim-dd
xcodebuild test -project Panim.xcodeproj -scheme Panim \
  -destination 'platform=iOS Simulator,name=iPad Pro 13-inch (M4)' -derivedDataPath /tmp/panim-dd
# static privacy checks and secret scan (gitleaks installed via Homebrew)
sh scripts/check-static.sh
gitleaks git . --no-banner --redact
gitleaks dir . --no-banner --redact
```
Tests: 6 unit tests (bundle contract: no permission strings, no queried schemes/ATS exceptions, iPhone+iPad, brand app icon declared, brand font loads in both used weights, font license bundled) and 1 UI launch test. They check the build contract, not product behavior.

## Running on your own device
The committed bundle identifier is the placeholder `invalid.panim.poc`. To install on a device, copy `Config/Signing.local.xcconfig.example` to `Config/Signing.local.xcconfig` (git-ignored), set `PANIM_BUNDLE_ID` to an identifier unique to your Apple developer team and `DEVELOPMENT_TEAM` to your team ID, then build in Xcode. Do not commit that file. The override mechanism was verified with `xcodebuild -showBuildSettings`; no device install has been performed yet.
